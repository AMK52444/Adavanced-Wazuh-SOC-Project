# Controlled Attack Simulations

## Overview

This directory documents authorized attack simulations conducted in the isolated SOC laboratory to validate Wazuh detection capabilities.

## Planned Test Scenarios

1. Suspicious PowerShell execution
2. Unauthorized file modification
3. Suspicious process execution
4. Persistence simulation
5. Repeated authentication failures

## Test Documentation

Each scenario will include:

- Objective
- Lab environment
- Simulation procedure
- Expected telemetry
- Observed Wazuh alerts
- MITRE ATT&CK mapping
- Investigation findings

## Status

In progress. Test results will be documented after execution and validation.
