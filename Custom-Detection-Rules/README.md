# Custom Wazuh Detection Rules

## Overview

This directory contains custom Wazuh detection rules developed to identify suspicious activities and security threats in the SOC laboratory.

## Planned Detection Categories

1. Suspicious PowerShell Execution
2. Unauthorized File Modifications
3. Suspicious Process Execution
4. Persistence Activity
5. Credential Access Indicators
6. Malware-Related Activity

## Detection Rule Documentation

Each rule will include:

- Rule ID and description
- Detection logic
- Relevant Windows Event IDs
- MITRE ATT&CK mapping
- Test procedure
- Expected alert
- Investigation and response recommendations

## Status

In progress. Rules will be added after implementation and validation in the Wazuh environment.
