# SOC Incident Investigation Reports

## Overview

This directory contains incident investigation reports generated during the Advanced Wazuh SOC project.

## Planned Investigation Scenarios

1. Suspicious PowerShell Activity
2. Unauthorized File Modification
3. Suspicious Process Execution
4. Multiple Failed Authentication Attempts
5. Suspicious Persistence Activity

## Report Structure

Each incident report will contain:

- Incident ID
- Incident description
- Severity and priority
- Detection timestamp
- Affected endpoint
- Alert details
- Investigation steps
- MITRE ATT&CK mapping
- Findings and evidence
- Recommended response actions

## Status

In progress. Incident reports will be added after successful detection and investigation in the laboratory.
