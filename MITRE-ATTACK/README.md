# MITRE ATT&CK Mapping

## Overview

This directory will document the mapping of validated security detections to the MITRE ATT&CK framework.

## Planned Techniques

- Execution
- Persistence
- Privilege Escalation
- Credential Access
- Defense Evasion
- Discovery

## Documentation

Each validated detection will include its ATT&CK tactic, technique ID, detection evidence, and investigation recommendations.

## Status

In progress. Technique mappings will be added after laboratory testing.
