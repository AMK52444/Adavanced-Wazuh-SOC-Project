# Advanced Wazuh SOC Project

## Advanced Threat Detection, Threat Hunting and Automated Incident Response Using Wazuh SIEM

**Project Status:** In Progress

## Overview

This project focuses on building an advanced Security Operations Center (SOC) lab using Wazuh SIEM to monitor endpoint activities, detect suspicious behavior, investigate security incidents, and implement automated incident response.

The lab uses Windows endpoint telemetry, Sysmon, custom detection rules, threat intelligence, and controlled attack simulations to demonstrate practical SOC operations.

## Objectives

- Centralized security event monitoring.
- Advanced endpoint threat detection.
- Windows event and Sysmon log analysis.
- Custom Wazuh detection rules.
- MITRE ATT&CK technique mapping.
- File Integrity Monitoring (FIM).
- Vulnerability detection.
- Threat intelligence integration.
- Automated incident response.
- Security incident documentation.
