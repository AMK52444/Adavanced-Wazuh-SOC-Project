# SOC Lab Architecture

## Overview

This directory contains the architecture and network design documentation for the Advanced Wazuh SOC project.

## Lab Components

- Kali Linux – Wazuh SIEM server.
- Windows 10 VM – Monitored endpoint.
- Kali Linux – Controlled attack simulation environment.
- Sysmon – Windows endpoint telemetry.

## Architecture Objectives

- Centralized security event collection.
- Endpoint monitoring.
- Security alert investigation.
- Threat detection and incident response.

## Architecture Status

Documentation in progress.

Network diagrams, IP addressing and communication flows will be documented after Phase 1 verification.
